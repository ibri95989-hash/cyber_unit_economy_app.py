# Панель Ozon на Windows — с самого начала

Инструкция для тех, кто никогда не открывал командную строку. Один раз
пройти всё — минут двадцать вместе со скачиванием. Потом запуск в один клик.

---

## Шаг 1. Поставить Python

Python — это программа, на которой всё работает. Ставится один раз.

1. Откройте **https://www.python.org/downloads/**
2. Нажмите жёлтую кнопку **Download Python**.
3. Запустите скачанный файл.
4. **Самое важное.** В первом окне установщика внизу есть галочка
   **«Add python.exe to PATH»** — поставьте её. Без неё компьютер не поймёт,
   где искать Python, и дальше ничего не заработает.
5. Нажмите **Install Now**, дождитесь надписи *Setup was successful*, закройте.

---

## Шаг 2. Скачать проект

1. Откройте страницу репозитория на GitHub.
2. Сверху переключите ветку на **`claude/ozon-api-integration-m313iz`**
   (кнопка со значком веточки, где написано `main`).
3. Зелёная кнопка **Code** → **Download ZIP**.
4. Найдите скачанный архив в папке «Загрузки», щёлкните правой кнопкой →
   **Извлечь всё** → **Извлечь**.
5. Получится папка с файлами. Перенесите её куда удобно — например, на
   рабочий стол. Путь лучше без пробелов и русских букв: `C:\ozon`.

---

## Шаг 3. Запустить

Зайдите в папку и найдите файл **`start_ozon.bat`**. **Двойной клик.**

Откроется чёрное окно — это нормально, так и должно быть. В первый раз оно
две-три минуты будет что-то устанавливать. Потом само откроется окно браузера
с панелью.

> **Чёрное окно закрывать нельзя.** Пока оно открыто — панель работает.
> Закроете его — панель погаснет. Свернуть можно.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
нажмите **Подробнее** → **Выполнить в любом случае**. Так бывает с любым
`.bat`-файлом, скачанным из интернета.

---

## Шаг 4. Взять ключи в Ozon

Нужны четыре значения из двух разных мест. Откройте кабинет Ozon в соседней
вкладке.

**Первая пара — Seller API** (товары, остатки, поставки):

1. Личный кабинет продавца → шестерёнка **Настройки**
2. Раздел **Seller API** → кнопка **Сгенерировать ключ**
3. Выберите роль:
   - **«Аналитик»** — только смотреть. Начните с неё, если не уверены.
   - **«Админ»** — смотреть и менять (создавать поставки).
4. Скопируйте **Client-Id** и **Api-Key**.

> Api-Key показывается **один раз**. Скопируйте сразу и вставьте в панель.
> Потеряете — не страшно, просто сгенерируете новый.

**Вторая пара — Performance API** (реклама и ставки):

1. Откройте **performance.ozon.ru** (рекламный кабинет).
2. **Реклама** → **API-ключи** → создать.
3. Скопируйте **Client ID** и **Client Secret**.

---

## Шаг 5. Вставить ключи в панель

В открывшейся панели слева форма. Вставьте четыре значения по своим полям и
нажмите **«Сохранить ключи»**.

Всё. Больше их вводить не придётся: они запишутся в файл `.env` в вашей папке.
Файл лежит только у вас на компьютере, никуда не отправляется и в интернет не
попадает.

Наверху появятся вкладки: **Поставки**, **Новая поставка**, **Остатки**,
**Реклама**, **Ставки**.

---

## Что вести вручную

Ничего. Все цифры панель берёт из Ozon сама — заполнять таблицы и выгружать
отчёты не нужно. Вы только смотрите и нажимаете кнопки.

Единственный файл, который появится сам, — **`ozon_audit.jsonl`**. В него
записывается каждое изменение: что, когда и ушло ли это в Ozon. Открывается
Блокнотом. Это ваша страховка: всегда видно, что именно было сделано.

---

## Как ничего не сломать

Слева есть тумблер **«Разрешить менять кабинет»**. Пока он выключен, панель
только смотрит: кнопки отправки серые, а «Посмотреть, что изменится» показывает
табличку «было → станет» и ничего не отправляет.

Совет на первое время: **не включайте его неделю**. Походите по вкладкам,
посмотрите на цифры, попробуйте предпросмотр ставок. Когда станет понятно, что
где — включите.

Рядом два ограничителя: **потолок ставки** и **максимальный шаг**. Если
промахнётесь нулём и введёте 350 ₽ вместо 35 ₽, панель остановит вас, даже
когда изменения разрешены.

---

## Как запускать потом

Тот же двойной клик по **`start_ozon.bat`**. Второй раз и дальше он открывается
за несколько секунд — устанавливать уже нечего.

Чтобы закончить работу: закройте вкладку браузера, потом чёрное окно.

Хотите ярлык на рабочий стол: правой кнопкой по `start_ozon.bat` →
**Отправить** → **Рабочий стол (создать ярлык)**.

---

## Если понадобится ввести команду вручную

Обычно не нужно — всё есть в панели. Но если попрошу что-то выполнить:

1. Откройте папку проекта в проводнике.
2. Щёлкните в **адресную строку** сверху (где написан путь).
3. Наберите `cmd` и нажмите **Enter**.

Откроется чёрное окно уже в нужной папке. Команды начинайте с
`.venv\Scripts\python -m` — например:

```
.venv\Scripts\python -m ozon.cli check
```

Это проверит, приняты ли ключи.

---

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «Python на компьютере не найден» | Python не установлен или забыта галочка «Add python.exe to PATH». Переустановите с галочкой. |
| Окно мигнуло и закрылось | Запустите `start_ozon.bat` ещё раз и сфотографируйте текст. Обычно причина написана прямо там. |
| «Система Windows защитила ваш компьютер» | **Подробнее** → **Выполнить в любом случае**. |
| Браузер не открылся сам | В чёрном окне будет строка вида `http://localhost:8501` — скопируйте её в браузер. |
| В панели «Ozon отклонил ключи» | Ключ скопирован не целиком или это ключ от другого кабинета. Сгенерируйте заново. |
| «Запись запрещена» | Включите тумблер «Разрешить менять кабинет» слева. |
| Кнопка «Создать заявку» серая | Не выбран склад или интервал, либо не поставлена галочка «Проверил состав». |

Не разобрались — скопируйте текст ошибки и покажите мне. По сообщению почти
всегда сразу видно, в чём дело.
