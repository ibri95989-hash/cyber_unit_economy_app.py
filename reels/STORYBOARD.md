# Reels «Выручка ≠ прибыль» — сториборд и visual language

Вертикальный ролик 9:16, 1080×1920, 30 fps, 106.5 с (озвучка 104.2 с + финальная карточка).
Рендер полностью процедурный: `reels/render_reels.py` (Pillow + numpy + ffmpeg), тайминг сцен и
субтитров берётся из пословных таймкодов озвучки `reels/words.json`.

## Visual language

| Элемент | Решение |
|---|---|
| Фон | тёмный tech-градиент `#07090F → #0C0E1A`, тонкая сетка 120 px, виньетка, дрейфующие glow-блобы (фиолет / циан / красный / золото / зелёный — по настроению сцены), 90 частиц с параллаксом по глубине |
| Типографика | Inter Display Black / ExtraBold — заголовки, Inter SemiBold / Medium — подписи; кинетика: slam (2.2× → 1), rise, посимвольный drop, elastic pop |
| Акценты | фиолет `#7C5CFF` (бренд), циан `#22D3EE` (оборот), золото `#FFB020` (выручка / деньги), красный `#FF4D6D` (потери), зелёный `#22E58A` (прибыль), magenta Wildberries |
| Эффекты | bloom-glow на каждом слое сцены, glassmorphism-карточки, light streaks, sparkles, glitch (RGB-split + слайсы), iris-маска, «камера» с дыханием зума и shake на ударных битах |
| Субтитры | динамические, 2–4 слова, перенос по ширине safe zone, активное слово подсвечивается золотом с pill-подложкой и лёгким scale, произнесённые — белые, будущие — приглушённые |
| Safe zone | весь текст в диапазоне y 300–1600, x 110–970 |

## Как пересобрать

```bash
pip install pillow numpy imageio-ffmpeg
python3 reels/render_reels.py --audio voiceover.mp3 --words reels/words.json --fonts reels/fonts --out reels.mp4
# один кадр для проверки:
python3 reels/render_reels.py --audio x --words reels/words.json --fonts reels/fonts --still 44.8 --out frame.png
```

`words.json` — список `{"w": слово, "s": старт, "e": конец}` (получен локальным ASR
`sherpa-onnx` + Parakeet-TDT 0.6B v3, затем вручную вычитан). Чтобы переозвучить ролик,
достаточно заменить аудио и файл таймкодов; сцены подстроятся под новые секунды только
после правки констант в `SCENES`.
