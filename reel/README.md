# ХАЙРУЛА — рекламный ролик 60 сек (Remotion)

Вертикальный ролик 1080×1920, ровно 60 секунд, 30 fps. Всё, что видно на
экране, сгенерировано кодом — сторонних видеоматериалов нет.

```bash
npm install
npm run dev      # Remotion Studio
npm run render   # → out/hairula-reel.mp4
npm run typecheck
```

## Монтаж ведёт голос, а не наоборот

Озвучка — один непрерывный дубль на 44,53 с. Его речевые фрагменты измерены
из самого аудио (`scripts/analyze-voice.mjs`), после чего дубль разрезан на
три части по паузам и заново разнесён по 60 секундам: иначе финальная фраза
«Хайрула. Монтаж, который работает на тебя.» звучала бы на 44-й секунде, за
12 секунд до логотипа.

Все склейки в `src/lib/timing.ts` стоят внутри измеренных пауз — монтаж
никогда не режет посреди слова. Ключевые слова привязаны к кадрам в `CUE`:
имя «Хайрула», четыре услуги, четыре «Для…», финальный слоган.

| Сцена | Кадры | Секунды | Голос |
|---|---|---|---|
| Хук | 0–270 | 0,0–9,0 | «Сегодня недостаточно…», «Я — Хайрула.» |
| Video editing | 270–402 | 9,0–13,4 | «Я превращаю обычные кадры…» |
| Motion design | 402–618 | 13,4–20,6 | «Монтаж. Моушн-графика. Дизайн. Рекламные ролики.» |
| RAW → PRO | 618–804 | 20,6–26,8 | «Я создаю динамику…» |
| Реклама | 804–963 | 26,8–32,1 | «Графику, которая объясняет…» |
| Ничего случайного | 963–1053 | 32,1–35,1 | «Каждый переход… От идеи — до результата.» |
| Для кого | 1053–1206 | 35,1–40,2 | «Для бизнеса. Для брендов…» |
| Showreel | 1206–1530 | 40,2–51,0 | — только музыка |
| Философия | 1530–1680 | 51,0–56,0 | «Если твоему контенту нужен новый уровень.» |
| Финал | 1680–1800 | 56,0–60,0 | «Хайрула. Монтаж, который работает на тебя.» |

## Звук

- `public/voiceover.mp3` — озвучка, мужской голос (ElevenLabs, Artem Lebedev,
  `eleven_multilingual_v2`).
- `public/score.mp3` — звуковой бэд, синтезированный из кода
  (`scripts/make-score.mjs`): дрон, пэд, сабовые удары на склейках, вуши на
  переходах, пульс 120 BPM под шоурил, райзер перед финалом. Удары стоят ровно
  на границах сцен.

Бэд намеренно нейтральный и служит подложкой. Если нужен полноценный
музыкальный трек — заменить `public/score.mp3` файлом той же длины (60,2 с);
границы сцен в `src/lib/timing.ts` уже лежат на сетке 120 BPM.

## Шрифты

Unbounded (дисплейный), Inter (интерфейс), JetBrains Mono (технические
подписи) — с кириллицей. Файлы `.woff2` лежат в `public/fonts`, подключаются
через `staticFile()` и загружаются до первого кадра (`src/lib/fonts.ts`), так
что рендер не зависит от сети и ни один кадр не может отрисоваться запасным
шрифтом.

Обновить набор: `node scripts/fetch-fonts.mjs && node scripts/build-font-faces.mjs`.

## Как устроен код

```
src/
  Reel.tsx          склейка сцен, аудио, акценты на стыках
  lib/theme.ts      палитра, типографическая шкала
  lib/motion.ts     кривые easing и детерминированный «рандом»
  lib/timing.ts     границы сцен и точки синхронизации с голосом
  lib/voice.ts      громкость голоса на конкретном кадре
  components/       фон, зерно, частицы, кинетическая типографика
  scenes/           десять сцен
```

Детерминизм — обязательное требование: `Math.random()` не используется нигде,
любое «случайное» значение выводится из индекса элемента и номера кадра
(`rand()` в `lib/motion.ts`). Два рендера дают идентичный результат.

Текст никогда не масштабируется по одной оси и не скашивается: буквы двигаются
и меняют прозрачность, размер — только равномерно. Размытие применяется как
имитация motion blur на быстрых движениях и полностью уходит в нуле скорости.
