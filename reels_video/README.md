# Reels Kit — вертикальный ролик из одной озвучки

Кидаете mp3 с озвучкой — получаете готовый Reels 9:16 с моушен-графикой,
инфографикой, динамическими субтитрами и переходами, синхронизированный
с речью по каждому слову.

Всё считается на вашем компьютере и офлайн: ни один сервис не вызывается,
интернет нужен только при первой установке.

---

## Самый короткий путь — 4 шага

**1.** Скачайте архив одним кликом:
[**⬇ скачать проект (ZIP)**](https://github.com/ibri95989-hash/cyber_unit_economy_app.py/archive/refs/heads/claude/professional-reels-video-8oqd7l.zip)

**2.** Распакуйте его и откройте папку `reels_video`.

**3.** Двойной клик по **`СТАРТ.bat`** (Windows) или **`СТАРТ.command`** (Mac).

**4.** Перетащите mp3 мышью в открывшееся окно и нажмите Enter.

Всё. Первый запуск сам поставит недостающее (около 10 минут, один раз),
дальше сразу пойдёт сборка. Готовый ролик появится в папке `out`,
она откроется автоматически.

> Если Python не установлен — `СТАРТ` скажет об этом и откроет страницу
> загрузки. Поставьте его, отметив галочку **«Add Python to PATH»**,
> и запустите `СТАРТ` заново.

## Как обновиться, когда программа изменится

Обновление — это тоже один клик:

**Windows** — двойной клик по `ОБНОВИТЬ.bat`
**macOS / Linux** — двойной клик по `ОБНОВИТЬ.command`

Скачается свежая версия и заменит только код. Ваш `brand.json` со всеми
правками, готовые ролики в `out` и уже скачанные шрифты останутся на месте;
новые настройки, если они появились, добавятся в `brand.json` сами,
не трогая ваши значения. На всякий случай рядом кладётся `brand.json.backup`.

Повторная установка после обновления не нужна: модель распознавания лежит
отдельно от папки проекта и заново не качается.

> Если у вас папка, скачанная до появления этой кнопки, — скачайте архив
> заново по ссылке из первого шага. Дальше обновляться можно кнопкой.

## Установка вручную

Нужен **Python 3.9 или новее**. Проверить: откройте терминал и наберите
`python --version` (на Mac — `python3 --version`). Если пишет «не найдено» —
скачайте с [python.org](https://www.python.org/downloads/).
**На Windows при установке обязательно отметьте галочку «Add Python to PATH».**

Если не хотите пользоваться `СТАРТ`, установку можно запустить отдельно:

**Windows** — двойной клик по `install.bat`

**macOS / Linux** — двойной клик по `install.command`,
либо в терминале: `python3 install.py`

Скрипт поставит библиотеки, Chromium для рендера, шрифты (Montserrat, Inter,
JetBrains Mono — лицензия OFL) и модель распознавания русской речи (~170 МБ).
Отдельно ставить ffmpeg не нужно.

## Если привычнее PowerShell (Windows)

Откройте PowerShell: **Win + X → Terminal** (или наберите `powershell` в меню «Пуск»).
Команды ниже вводятся по одной, после каждой — Enter.

```powershell
# 1. Проверяем Python. Должно ответить "Python 3.x.x"
py --version

# 2. Скачиваем проект на рабочий стол
cd $HOME\Desktop
git clone -b claude/professional-reels-video-8oqd7l https://github.com/ibri95989-hash/cyber_unit_economy_app.py.git
cd cyber_unit_economy_app.py\reels_video

# 3. Установка. Один раз, минут десять
py install.py

# 4. Сборка ролика. Путь к mp3 можно не набирать:
#    напишите  py make_reel.py  пробел  и перетащите файл мышью в окно PowerShell
py make_reel.py "$HOME\Desktop\voice.mp3"

# 5. Открыть папку с готовым роликом
explorer out
```

Полезное:

```powershell
py make_reel.py voice.mp3 --preview 0.4,17.2,40.1        # только отдельные кадры
py make_reel.py voice.mp3 --crf 22 --preset medium       # версия полегче
py make_reel.py voice.mp3 --brand clients\barbershop.json
py make_reel.py voice.mp3 --no-sfx                       # без звуковых эффектов # свои тексты и цифры
```

### Что может пойти не так в PowerShell

**`py` не найдено** — попробуйте `python` вместо `py`. Если открывается
Microsoft Store, значит Python не установлен: скачайте с
[python.org](https://www.python.org/downloads/) и отметьте
«Add Python to PATH».

**`git` не найдено** — скачайте проект как ZIP: на странице репозитория
**Code → Download ZIP**, распакуйте, затем перейдите в папку командой
`cd` (путь можно перетащить мышью в окно).

**Хотите запустить `.bat` из PowerShell** — нужна точка со слешем впереди:
`.\make_reel.bat voice.mp3`, иначе PowerShell файл не найдёт.

**В пути есть пробелы или кириллица** — берите путь в кавычки:
`py make_reel.py "C:\Мои файлы\озвучка.mp3"`.

## Как пользоваться

**Самый простой способ.** Перетащите mp3 мышью на `make_reel.bat` (Windows)
или на `make_reel.command` (Mac) — откроется окно, пойдёт сборка, готовый
ролик появится в папке `out`.

**Из терминала**, если нужны настройки:

```bash
# озвучка на входе, ролик на выходе
python make_reel.py voice.mp3

# свой путь и свои тексты
python make_reel.py voice.mp3 -o out/promo.mp4 --brand clients/barbershop.json

# посмотреть отдельные кадры, не ожидая полного рендера
python make_reel.py voice.mp3 --preview 0.4,17.2,40.1

# облегчённая версия для мессенджеров (лимит 30 МБ и меньше)
python make_reel.py voice.mp3 -o out/promo_web.mp4 --crf 22 --preset medium

# черновик на скорость: в 3–4 раза быстрее, качество ниже
python make_reel.py voice.mp3 --crf 26 --preset veryfast --fps 24
```

### Сколько это занимает

Считает почти всё видеокарта и процессор, поэтому время сильно зависит
от машины. Ориентир для ролика 45 секунд:

| Машина | Рендер |
|---|---|
| Ноутбук с дискретной видеокартой | 1–3 минуты |
| Обычный офисный ноутбук | 4–8 минут |
| Слабая виртуалка без GPU | 20+ минут |

Повторный прогон с `--transcript` пропускает распознавание и экономит
ещё около минуты.

## Что подстраивается под озвучку, а что нет

**Цифры берутся из речи.** Сказали «рост в пять раз» — на графике будет `×5`.
Сказали «удержание восемьдесят семь процентов» — в дашборде `87%`.
Числа распознаются прописью («двенадцать тысяч пятьсот»), а смысл определяется
по соседнему слову: «подписчиков» — это аудитория, «просмотров» — охват,
«процентов» рядом с «удержанием» — удержание. Чего в озвучке нет, берётся
из `brand.json`.

**Иконки подбираются по словам.** В движке 49 векторных иконок и словарь
из 34 тем: доставка, товар, сроки, отзывы, гарантия, сервис, тренировки,
недвижимость, транспорт, обучение, бизнес, цена, прибыль, скидка, клиенты,
связь, онлайн, подбор, результат, запуск, тренд, конфиденциальность, бонус,
абонемент, здоровье, эко, качество, консультация, договор, замер, скорость,
опыт и другие. Сказали «доставка» — появится грузовик, «гарантия» — щит.

**Цепочка производства собирается из названных этапов.** Кроме медийных
(идея, сценарий, AI, визуал, озвучка, монтаж, субтитры) движок знает
консультацию, замер, договор, производство, доставку, установку, обучение
и гарантию. Если этапов в речи меньше двух, цепочка не выдумывается —
сцена становится крупной типографикой.

**Звук синтезируется под тайм-коды.** Удары, свисты на переходах, подъёмы,
тики на счётчиках, шиммер на раскрытиях и низкая подложка — всё считается
кодом, ничего не скачивается и не требует лицензий. Эффекты приглушаются
под речью и попадают ровно в момент появления слова. Выключается ключом
`--no-sfx`, громкость — `--sfx-level 0.3`.

**Фирменный стиль одинаков всегда** — шрифты, палитра, свечение, набор
переходов. Это сделано намеренно: все ваши ролики выглядят как работы
одной студии.

**Чего движок не умеет.** Он собирает ролик из готовой библиотеки сцен
и иконок, а не рисует новую графику под незнакомую тему. Фразы, не попавшие
ни в одну тему, идут в запасную сцену крупной типографики — в том же стиле,
но менее конкретно.

## Анимированные иконки и фоны

**Фоны считает шейдер.** Вместо плоской заливки под сценой течёт объёмный
градиент: домен-варпинг по шуму fBm, объёмный свет, световой луч, виньетка
и зерно. Семь палитр, своя под настроение каждой сцены — тревожная красная
под расходами, денежная зелёная под результатом, фиолетовая под призывом.
Считается видеокартой во время рендера: ничего не скачивается и не стоит
денег, а фон живой, а не статичная картинка.

На слабой машине шейдер можно удешевить или выключить:

```bash
python make_reel.py voice.mp3 --bg fast     # вчетверо дешевле
python make_reel.py voice.mp3 --bg off      # только градиент, самый быстрый рендер
```

**Анимированные иконки — Lottie.** Положите файлы `.json` в папку
`assets/motion/` — программа найдёт их сама и подставит вместо статичных.
Имя файла это ключ: `truck.json` заменит иконку грузовика, `shield-check.json`
— щит. Анимация играет по времени ролика, а не по часам браузера, поэтому
в покадровом рендере она не разъезжается с видео.

Где брать бесплатно — в [assets/motion/README.md](assets/motion/README.md).
Проигрыватель (lottie-web, MIT) уже внутри, качать ничего не нужно.

**Иконки — три стиля на выбор.** Внутри два набора: 1792 контурных иконки
Lucide (ISC) и 1512 иконок Phosphor (MIT) в заливке и в двухслойном
«дуотоне». Стиль переключается одной строкой в `brand.json`:

```json
"iconStyle": "stroke"
```

| значение | как выглядит |
|----------|--------------|
| `stroke` | тонкий контур, воздушно и строго — по умолчанию |
| `fill`   | плотная заливка, максимальный контраст, хорошо читается в ленте |
| `duo`    | заливка плюс полупрозрачный второй слой, объёмнее и дороже на вид |

Lottie-анимация, если файл для иконки лежит в `assets/motion/`, всегда
главнее и играет поверх любого стиля.

**Шрифты.** Ставится семь семейств с полной кириллицей, все под OFL:
Montserrat, Inter, JetBrains Mono, Unbounded, Oswald, Golos Text, Manrope.
Пара для ролика задаётся в `brand.json`:

```json
"fonts": { "display": "Montserrat.ttf", "body": "Inter.ttf", "mono": "JetBrainsMono.ttf" }
```

`display` — крупные заголовки и субтитры, `body` — подписи и мелкий текст,
`mono` — цифры и счётчики. Готовые сочетания:

| настроение | display | body |
|------------|---------|------|
| нейтрально-деловое | `Montserrat.ttf` | `Inter.ttf` |
| дерзкое, техно | `Unbounded.ttf` | `GolosText.ttf` |
| плакатное, узкое | `Oswald.ttf` | `Manrope.ttf` |

Можно положить в `src/` свой `.ttf` и написать его имя — лишь бы в шрифте
была кириллица, иначе текст поедет.

## Что можно менять без программиста

**`brand.json`** — все надписи, цифры инфографики и написание слов на экране.
Поменяйте `"growth": 340` на свою реальную цифру, `"ctaLockup"` на свой призыв,
добавьте в `"spelling"` название вашей компании, если распознавание пишет его
неправильно. Кода это не касается. Там же `"iconStyle"` и `"fonts"` —
стиль иконок и шрифтовая пара, см. раздел выше.

**План сцен** — если автоматическая раскладка не понравилась:

```bash
python make_reel.py voice.mp3 --dump-plan plan.json   # выгрузить
# поправить plan.json руками: границы сцен, тайм-коды, тексты
python make_reel.py voice.mp3 --plan plan.json        # собрать по нему
```

## Как ролик собирается сам

1. **Расшифровка.** Озвучка распознаётся офлайн (sherpa-onnx, русская модель
   GigaAM v2 CTC + Silero VAD) с тайм-кодом каждого слова.

2. **Раскладка на сцены.** Речь режется на фразы по паузам, каждая фраза
   оценивается по словарям тем, а последовательность сцен выбирается алгоритмом
   Витерби: сцена «липнет» к предыдущей, ходить назад по сюжету дорого.
   Поэтому раскладка получается связной, а не скачет от фразы к фразе.
   Дальше внутри каждой сцены тайм-код каждого движения привязывается
   к конкретному слову: штамп «СКУЧНО» падает на слове «скучные», узел
   «ОЗВУЧКА» загорается на слове «озвучку». Не нашлось слова — берётся
   доля от длительности сцены.

3. **Отрисовка.** `src/reel.js` — детерминированный движок: одна функция
   `render(t)` рисует кадр для любого момента. Никакой логики выбора сцен
   в нём нет, он рисует ровно то, что описано в плане.

4. **Кодирование.** Кадры снимаются в headless Chromium и идут прямо в ffmpeg.
   Озвучка нормализуется до −14 LUFS (уровень Instagram, TikTok, YouTube)
   и подкладывается без перекодирования видео.

### Сцены

`hook` — слэм-типографика · `boring` — скучный статичный фид · `comp` —
сравнение с конкурентами (сплит, таймер, графика, динамика, AI) · `scroll` —
аудитория листает дальше · `pipe` — цепочка производства из этапов, которые
диктор перечислил · `noeff` — «вам не нужно…» с перечёркнутыми карточками ·
`result` — дашборд результата · `cta` — призыв с DM-перепиской · `kinetic` —
запасная сцена крупной типографики для фраз, не попавших ни в одну тему.

Сцена появляется только если о ней говорят. Нет в озвучке слова про монтаж —
не будет и узла «МОНТАЖ». Короткий финал — блок с вирусным графиком
выключается сам, чтобы не наезжать на границу.

## Если что-то пошло не так

**Первым делом — проверка.** Двойной клик по `ПРОВЕРКА.bat` (Windows)
или `ПРОВЕРКА.command` (Mac), либо `python make_reel.py --check`.
Она пройдёт по всем частям и скажет, что именно сломано и что с этим делать.

### Ролик получился кривой: текст налезает, вёрстка разъехалась

Почти всегда это шрифты. Если они не докачались или вместо шрифта скачалась
страница ошибки, браузер молча подставляет системный — и весь макет плывёт.
Программа теперь проверяет шрифты по содержимому и отказывается собирать
ролик с битыми, но если у вас старая версия — обновитесь и запустите проверку.

**Chromium не ставится** — `python -m playwright install chromium` вручную.

**Ролик тяжелее 30 МБ** для отправки в мессенджер — пересоберите
с `--crf 22 --preset medium`.

**Распознавание путает слова** — добавьте замену в `brand.json` → `spelling`.
На тайминги это не влияет, только на надписи.

**Сцены разложились не так** — выгрузите план через `--dump-plan`,
поправьте и соберите с `--plan`.
