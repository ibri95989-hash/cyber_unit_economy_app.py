# Аудио

Сюда кладутся аудиофайлы чтения азкаров.

## Как подключить аудио к записи

1. Положите файл в этот каталог, например `public/audio/morning-01-ayat-al-kursi.mp3`.
2. В соответствующем файле данных (`data/azkar/*.ts`) добавьте записи поле:

   ```ts
   audioUrl: '/audio/morning-01-ayat-al-kursi.mp3',
   ```

Если `audioUrl` не указан, интерфейс честно пишет «Аудио для этой записи пока
не добавлено» — вместо нерабочей кнопки.

## Требования

- Формат: `.mp3` или `.m4a` — их понимают все мобильные браузеры.
- Битрейт: 64–96 kbps моно. Для речи этого достаточно, а трафик экономится.
- Имя файла = id записи. Так сразу видно, что к чему относится.

## Права

Не загружайте чужие записи без разрешения правообладателя. Если запись сделана
не вами — сохраните подтверждение лицензии рядом с файлом.

## Кеширование

Service worker намеренно **не** кеширует аудио: диапазонные запросы плохо
дружат с Cache API, а библиотека чтений быстро переполнила бы хранилище
устройства. Тексты при этом доступны офлайн полностью.
