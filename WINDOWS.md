# Панель Ozon на Windows — с самого начала

Инструкция для тех, кто никогда не открывал командную строку. Один раз
пройти всё — минут двадцать вместе со скачиванием. Потом запуск в один клик.

---

## Шаг 1. Поставить Python

Python — это программа, на которой всё работает. Ставится один раз.

1. Откройте **https://www.python.org/downloads/**
2. Нажмите жёлтую кнопку **Download Python**.
3. Запустите скачанный файл.
4. **Самое важное.** В первом окне установщика внизу есть галочка
   **«Add python.exe to PATH»** — поставьте её. Без неё компьютер не поймёт,
   где искать Python, и дальше ничего не заработает.
5. Нажмите **Install Now**, дождитесь надписи *Setup was successful*, закройте.

---

## Шаг 2. Скачать проект

**Прямая ссылка — просто откройте её в браузере:**

https://github.com/ibri95989-hash/cyber_unit_economy_app.py/archive/refs/heads/claude/ozon-api-integration-m313iz.zip

Скачается файл `cyber_unit_economy_app.py-claude-ozon-api-integration-m313iz.zip`
(около 100 КБ). Никуда входить и ничего нажимать не нужно.

Дальше:

1. Откройте папку **«Загрузки»** и найдите этот архив.
2. Щёлкните по нему правой кнопкой → **Извлечь всё…** → **Извлечь**.
3. Внутри окажется папка с длинным именем
   `cyber_unit_economy_app.py-claude-ozon-api-integration-m313iz`.
   Переименуйте её в **`ozon`** (правой кнопкой → Переименовать) и перенесите
   в корень диска C — чтобы получился путь **`C:\ozon`**.
4. Откройте `C:\ozon` и убедитесь, что файл **`start_ozon.bat`** лежит прямо
   там, а не внутри ещё одной вложенной папки. Если он на уровень глубже —
   поднимите содержимое наверх.

<details>
<summary>Если хочется через сайт, а не по ссылке</summary>

Откройте репозиторий на GitHub → кнопка со значком веточки (там написано
`main`) → выберите **`claude/ozon-api-integration-m313iz`** → зелёная кнопка
**Code** → **Download ZIP**.

</details>

## Шаг 3. Запустить

Зайдите в папку и найдите файл **`start_ozon.bat`**. **Двойной клик.**

Откроется чёрное окно — это нормально, так и должно быть. В первый раз оно
две-три минуты будет что-то устанавливать. Потом само откроется окно браузера
с панелью.

> **Чёрное окно закрывать нельзя.** Пока оно открыто — панель работает.
> Закроете его — панель погаснет. Свернуть можно.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
нажмите **Подробнее** → **Выполнить в любом случае**. Так бывает с любым
`.bat`-файлом, скачанным из интернета.

---

## Шаг 4. Взять ключи в Ozon

Нужны четыре значения из двух разных мест. Откройте кабинет Ozon в соседней
вкладке.

**Первая пара — Seller API** (товары, остатки, поставки):

1. Личный кабинет продавца → шестерёнка **Настройки**
2. Раздел **Seller API** → кнопка **Сгенерировать ключ**
3. Ozon покажет длинный список галочек «Типы токена» — это права ключа.
   Проще всего отметить одну:

   **`Admin read only`** — «все информационные методы Seller API без внесения
   изменений». Панель сможет показывать всё, но физически не сможет ничего
   изменить в кабинете, даже если очень захочет.

4. Скопируйте **Client-Id** и **Api-Key**.

Когда дойдёте до создания поставок, ключ нужно будет пересоздать, добавив к
`Admin read only` галочку **`Supply order`** — это право менять поставки FBO
(черновики, создание заявки, перенос интервала, отмена).

<details>
<summary>Если хочется отметить только необходимое, без Admin read only</summary>

| Что заработает в панели | Какие галочки нужны |
|---|---|
| Проверка ключа, список складов и кластеров | `Warehouse` |
| Остатки товаров | `Stocks`, `Product read-only` |
| Остатки в разрезе складов, аналитика продаж | `Report` |
| Отправления FBS | `Posting FBS read-only` |
| Поставки — только смотреть | `Supply order ReadOnly` |
| Поставки — создавать и отменять | `Supply order` |

Остальные галочки в списке (чаты, отзывы, вопросы, акции, сертификаты, FBP)
панели не нужны.

</details>

> Api-Key показывается **один раз**. Скопируйте сразу и вставьте в панель.
> Потеряете — не страшно, просто сгенерируете новый.

**Вторая пара — Performance API** (реклама и ставки):

1. Откройте **performance.ozon.ru** (рекламный кабинет).
2. **Реклама** → **API-ключи** → создать.
3. Скопируйте **Client ID** и **Client Secret**.

---

## Шаг 5. Вставить ключи в панель

В открывшейся панели слева форма. Вставьте четыре значения по своим полям и
нажмите **«Сохранить ключи»**.

Всё. Больше их вводить не придётся: они запишутся в файл `.env` в вашей папке.
Файл лежит только у вас на компьютере, никуда не отправляется и в интернет не
попадает.

Наверху появятся вкладки: **Поставки**, **Новая поставка**, **Остатки**,
**Реклама**, **Ставки**.

---

## Что вести вручную

Ничего. Все цифры панель берёт из Ozon сама — заполнять таблицы и выгружать
отчёты не нужно. Вы только смотрите и нажимаете кнопки.

Единственный файл, который появится сам, — **`ozon_audit.jsonl`**. В него
записывается каждое изменение: что, когда и ушло ли это в Ozon. Открывается
Блокнотом. Это ваша страховка: всегда видно, что именно было сделано.

---

## Как ничего не сломать

Слева есть тумблер **«Разрешить менять кабинет»**. Пока он выключен, панель
только смотрит: кнопки отправки серые, а «Посмотреть, что изменится» показывает
табличку «было → станет» и ничего не отправляет.

Совет на первое время: **не включайте его неделю**. Походите по вкладкам,
посмотрите на цифры, попробуйте предпросмотр ставок. Когда станет понятно, что
где — включите.

Рядом два ограничителя: **потолок ставки** и **максимальный шаг**. Если
промахнётесь нулём и введёте 350 ₽ вместо 35 ₽, панель остановит вас, даже
когда изменения разрешены.

---

## Как обновлять

Никак — панель обновляется сама. Каждый запуск `start_ozon.bat` сначала
подтягивает свежую версию, потом открывает окно. Ключи и журнал при этом не
трогаются.

Версия видна слева внизу, под кнопкой «Обновить данные». По ней сразу понятно,
какая сборка работает, — это избавляет от разбора ошибок, которых в новом коде
уже нет.

`update_ozon.bat` остался для случая, когда нужно обновиться, не запуская
панель.

## Показать данные Claude в любом чате

Двойной клик по **`snapshot.bat`** — он соберёт остатки, товары, поставки и
аналитику в один файл и откроет папку с ним. Перетащите `ozon_snapshot.json`
в переписку с Claude, и он увидит ваш кабинет: хоть в приложении, хоть в
браузере, хоть в облачной сессии. Ключи в файл не попадают.

Это не требует ни MCP-сервера, ни настроек — работает всегда.

## Если что-то не работает

Вкладка **«Проверка»** → кнопка **«Проверить всё»**. Панель пройдёт по всем
методам Ozon, которыми пользуется, и покажет таблицу: что отвечает, что закрыто
правами ключа, где ошибка в запросе. Один скриншот этой таблицы заменяет
переписку по каждой вкладке отдельно.

То же самое из терминала:

```
.venv\Scripts\python -m ozon.cli doctor
```

---

## Как запускать потом

Тот же двойной клик по **`start_ozon.bat`**. Второй раз и дальше он открывается
за несколько секунд — устанавливать уже нечего.

Чтобы закончить работу: закройте вкладку браузера, потом чёрное окно.

Хотите ярлык на рабочий стол: правой кнопкой по `start_ozon.bat` →
**Отправить** → **Рабочий стол (создать ярлык)**.

---

## Спрашивать у Claude словами

Панель показывает данные, но ходить по вкладкам не всегда удобно. Можно
подключить кабинет к Claude и спрашивать обычным языком: «какой остаток на
складах», «что заканчивается», «покажи заявки на поставку».

1. Двойной клик по **`setup_claude.bat`** в папке с панелью
2. Полностью закройте приложение Claude и откройте заново
3. Спросите: *какой у меня остаток*

`setup_claude.bat` сам разберётся, как подключиться: сначала попробует
командную строку Claude Code, а если её нет — пропишет сервер прямо в
настройки приложения Claude. Чужие серверы и настройки при этом не трогаются,
старый файл сохраняется рядом с пометкой `.backup`.

Если ни командной строки, ни приложения на компьютере нет — установите Claude
со страницы https://claude.com/claude-code и запустите файл заново.

Ключи при этом остаются у вас: сервер запускается на вашем компьютере и берёт
их из того же файла `.env`. В переписку попадают только ответы Ozon.

Тумблер «Разрешить менять кабинет» слева в панели теперь общий: он
сохраняется в `.env`, и его видит не только панель, но и Claude. Выключен —
оба только смотрят. Включён — оба могут менять ставки, а поставки всё равно
требуют отдельного подтверждения.

Что Claude сможет делать, определяется тремя вещами:

| Уровень | Как открыть |
|---|---|
| Смотреть всё | ключ `Admin read only` — уже есть |
| Менять ставки | тумблер в панели |
| Создавать и отменять поставки | пересоздать ключ, добавив `Supply order` |
| Реклама и ставки | ввести ключи Performance API в форму слева |

Проверить, что подключение на месте: `claude mcp list`. Отключить:
`claude mcp remove ozon`.

## Если понадобится ввести команду вручную

Обычно не нужно — всё есть в панели. Но если попрошу что-то выполнить:

1. Откройте папку проекта в проводнике.
2. Щёлкните в **адресную строку** сверху (где написан путь).
3. Наберите `cmd` и нажмите **Enter**.

Откроется чёрное окно уже в нужной папке. Команды начинайте с
`.venv\Scripts\python -m` — например:

```
.venv\Scripts\python -m ozon.cli check
```

Это проверит, приняты ли ключи.

---

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «Python на компьютере не найден» | Python не установлен или забыта галочка «Add python.exe to PATH». Переустановите с галочкой. |
| Окно мигнуло и закрылось | Запустите `start_ozon.bat` ещё раз и сфотографируйте текст. Обычно причина написана прямо там. |
| «Система Windows защитила ваш компьютер» | **Подробнее** → **Выполнить в любом случае**. |
| Браузер не открылся сам | В чёрном окне будет строка вида `http://localhost:8501` — скопируйте её в браузер. |
| В панели «Ozon отклонил ключи» | Ключ скопирован не целиком или это ключ от другого кабинета. Сгенерируйте заново. |
| «Запись запрещена» | Включите тумблер «Разрешить менять кабинет» слева. |
| Кнопка «Создать заявку» серая | Не выбран склад или интервал, либо не поставлена галочка «Проверил состав». |

Не разобрались — скопируйте текст ошибки и покажите мне. По сообщению почти
всегда сразу видно, в чём дело.
