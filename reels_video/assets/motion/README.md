# Анимированные иконки (Lottie)

Складывайте сюда файлы `.json` — они автоматически попадут в ролик.

Где брать бесплатно:
- [lottiefiles.com/free-animations](https://lottiefiles.com/free-animations) — большой бесплатный раздел
- [icons8.com/animated-icons](https://icons8.com/animated-icons) — бесплатно со ссылкой на источник
- [lordicon.com/icons?price=free](https://lordicon.com/icons?price=free) — бесплатный набор

Проверяйте лицензию: часть файлов бесплатна только для личного использования.

## Как это работает

Программа сама находит все `.json` в этой папке. Имя файла — это ключ,
по которому анимация подставляется вместо статичной иконки.

Назовите файл так же, как тему из словаря, и он заменит её иконку:

    доставка.json    → вместо иконки грузовика
    гарантия.json    → вместо щита
    прибыль.json     → вместо монеты

Список тем — в `pipeline/plan.py`, таблица `ICON_MAP`.
Можно и латиницей: `truck.json`, `shield-check.json` — по имени иконки Lucide.
