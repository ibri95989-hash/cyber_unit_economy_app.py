# Reels 9:16 — покадровый сценарий

Ниже разобран **эталонный ролик**, собранный из приложенной озвучки.
Он не задан руками: сцены, тайм-коды и переходы посчитал `pipeline/plan.py`
из распознанной речи. Для любой другой озвучки раскладка будет своя —
как именно она считается, описано в [README](README.md).

Формат: **1080×1920, 30 fps, 45.6 c** (озвучка 43.55 c + 2 c финального лока).

## Субтитры

Динамические, 1–3 слова в группе, верхний регистр, Montserrat 900.
Активное слово подсвечивается градиентом, увеличивается и получает мягкое свечение;
уже произнесённые — белые, ещё не произнесённые — приглушённые.
Группы нарезаны по пословным тайм‑кодам ASR (`src/words.js`), с учётом пауз,
границ сцен и длины строки. Субтитры скрыты там, где крупная типографика
сама несёт текст (хук и финальный призыв).

## Переходы (не повторяются подряд)

`glitch` (RGB‑split + блочное смещение) · `whip` (панорама со смазом) ·
`ramp` (speed ramp: разгон + блюр) · `iris` (раскрытие круга) ·
`match` (пролёт сквозь объект) · `streak` (световая шторка) ·
`punch` (зум‑удар + вспышка).

Внутри сцен смена картинки происходит каждые 1–3 секунды: микро‑сцены,
шок‑кольца, вспышки, счётчики, пошаговое появление элементов.

## Как это повторить

```bash
python make_reel.py voice.mp3
```

Границы сцен и тайм-коды внутри них можно выгрузить и поправить руками:

```bash
python make_reel.py voice.mp3 --dump-plan plan.json
python make_reel.py voice.mp3 --plan plan.json
```
